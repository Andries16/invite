# Experience Model

Invite.md is an AI-powered platform for creating interactive experiences, with invitations as the core use case.

An Experience is a playable guest journey composed from scenes, content, media, motion, audio, triggers and interactions. An invitation is one use case for an Experience.

## Core flow

Intent -> Conversation -> Storyboard -> ExperienceSpec -> Scenes -> Preview / Play -> Validation -> Generation -> Publish

## Scene model

Each scene has an order, purpose, trigger, content, media, motion, interaction references and optional duration.

The same normalized experience representation drives creator preview, Play as guest and production generation.

## Campaigns

A master Experience can be reused for hundreds of recipients. Safe variables include guest name, photo, message, code, table and RSVP URL.

## Analytics

Analytics follow the guest journey: session start, scene reached, interaction started, interaction completed, reveal, RSVP and completion.

## Product principle

The platform should make the user feel unrestricted while keeping the runtime controlled, validated, responsive and deterministic underneath.
