# Invite.md Platform Capabilities

Status: Proposed product foundation.

Invite.md is an AI Experience Studio. Invitations are the first major use case, but the platform is designed around a reusable experience engine.

## Capability map

| Area               | Foundation                                | Expansion                                              |
| ------------------ | ----------------------------------------- | ------------------------------------------------------ |
| AI creation        | conversational intake, structured answers | story ingestion, creative director, iterative patches  |
| Experiences        | scenes, triggers, interactions            | branching, games, secret/time unlocks                  |
| Design             | visual languages, design tokens           | reusable themes, creator marketplace                   |
| Media              | upload + processing boundary              | AI editing, smart crops, video clips, generated assets |
| Personalization    | typed variables                           | campaigns, dynamic guest content                       |
| Public interaction | isolated interaction API                  | RSVP, quizzes, guestbook, voting, photo uploads        |
| Publication        | stable URL + immutable artifact           | custom domains, edge routing                           |
| QR                 | stable logical destination                | QR campaigns, physical print workflows                 |
| Analytics          | privacy-aware event model                 | funnels, campaign analytics                            |
| Localization       | schema-ready content                      | multilingual AI adaptation                             |
| Export             | static artifact                           | PDF, ZIP, video/social exports                         |
| Collaboration      | project boundary                          | teams, comments, roles                                 |
| Commerce           | billing boundary                          | plans, credits, marketplace                            |
| Ecosystem          | recipes                                   | public/private experience marketplace                  |

## Product pillars

1. Story — capture the user's real story and intent.
2. Creativity — AI acts as creative director, copywriter and experience planner.
3. Experience — guests receive an interactive journey, not a generic landing page.
4. Personalization — one experience can safely serve many recipients.
5. Media — photos, video, GIF, audio and generated assets are first-class.
6. Interaction — public experiences can collect controlled guest input.
7. Distribution — stable URLs, QR codes, custom domains and physical outputs.
8. Intelligence — analytics describe the guest journey.
9. Reuse — recipes, themes, components and campaign templates compound over time.
10. Safety — AI and user data stay inside explicit, validated boundaries.

Every capability must map to an owner domain, package boundary, API contract, persistence model, background job where needed, and acceptance tests.
